# 실데이터 수집 가이드 — 부족한 감정 집중 (놀람·당황·슬픔·고마움)

## 왜 이걸 하나
지금 모델은 실데이터 test에서 **놀람·당황·슬픔·고마움 = F1 0**이에요.
실제 커플 대화(1주일/2년차/싸움 시나리오)에 이 감정이 거의 안 나와서, **학습도 검증도 안 됩니다.**
합성으로 커버는 했지만 말투가 깔끔해서 실채팅과 갭이 커요. → **진짜 대화를 조금만 모으면 성능 천장이 올라갑니다.**

목표: **각 감정 실데이터 30~50개** (메시지 수 기준). 감정당 짧은 롤플레이 대화 2~3개면 충분.

---

## 롤플레이 방법 (팀원끼리 카톡으로)
- 한 명이 아래 **"대화 시작 문장"** 중 하나로 상황을 던지고, 자연스럽게 이어가세요.
- **감정 단어를 억지로 넣지 마세요.** ("나 놀랐어" 대신 "헐 진짜?? 갑자기??" 처럼 자연스럽게)
- 한 대화에 여러 감정 섞여도 OK (라벨은 메시지 1개 단위로 달아요).
- 슬픔은 민감하니 **가상 설정**으로 편하게. 무리하지 마세요.

### 😲 놀람 — 예상 밖 소식/사건에 즉각 반응
> 시작 문장 예 (한 명이 던지기):
- "나 사실 다음 달에 교환학생 붙었어"
- "너 그거 들었어? 우리 과 갑자기 종강 앞당겨진대"
- "나 방금 길에서 연예인 봤잖아"
- "우리 예약한 데 갑자기 문 닫았대"
- "나 시험 만점 나왔어"
→ 상대는 "헐/뭐/진짜?/갑자기?/말도 안 돼" 식으로 반응하게 됩니다. 그 **반응 메시지**가 놀람.

### 😳 당황 — 예상 못한 진지한 말/상황/들킴에 어쩔 줄 모름
> 시작 문장 예:
- "우리 부모님이 너 보고 싶으시대 이번 주말 어때"
- "나 사실 너한테 서운한 거 있어" (갑자기 진지)
- "나 지금 너희 집 앞이야"
- "너 아까 그거 다 봤어" (실수 들킴)
- "우리 오늘 만나기로 한 거 잊었지"
→ "어?/헉/갑자기?/어떡하지/나 뭐라고 해야 하지" 반응이 당황.

### 😢 슬픔 — 상실/이별/실패에 대한 위로 대화 (가상 설정 OK)
> 시작 문장 예:
- "나 오래 키우던 강아지가 무지개다리 건넜어"
- "나 이번에도 시험 떨어졌어"
- "할머니가 편찮으셔"
- "나 오늘따라 너무 우울해"
→ 상대의 위로("어떡해.. 많이 힘들었겠다"), 당사자의 슬픔 모두 라벨 대상.

### 🙏 고마움 — 배려·도움·선물·기다림에 진심 감사
> 시작 문장 예:
- "너 아프다길래 죽 사놨어 문 앞에 있어"
- "발표자료 내가 미리 정리해뒀어"
- "역까지 데리러 왔어"
- "천천히 해도 돼 내가 기다릴게"
- "네가 좋아할 것 같아서 예약해놨어"
→ "이런 것까지.. 진짜 고마워/덕분이야" 반응이 고마움.

> 💡 이왕이면 놀람↔기쁨, 당황↔부끄러움 처럼 헷갈리는 경계도 자연스럽게 나오게 두세요.
> 그런 경계 데이터가 모델을 더 똑똑하게 만듭니다.

---

## 모은 뒤 처리 (파이프라인)

1. **카톡에서 대화 내보내기** → `.txt` (두 형식 다 지원됨)

2. **CSV로 변환** (Anaconda Prompt, `AI/training` 폴더에서)
   ```bat
   chcp 65001
   conda activate emotion
   set PYTHONUTF8=1
   python kakao_to_label_csv.py data "C:\경로\내보낸대화.txt"
   ```
   → `data\to_label_<방이름>.csv` 생성.

3. **엑셀로 열어 `label` 칸 채우기** (15개 중 하나). 애매하면 비워두면 학습에서 자동 제외.

4. **채운 CSV를 `data\modify_data\` 에 넣기.**
   ⚠️ 파일명이 **`to_label_` 또는 `done_to_label_`** 로 시작해야 '실데이터'로 인식됩니다.
   (엑셀 저장 시 인코딩이 cp949여도 병합 스크립트가 자동으로 읽어요.)

5. **다시 병합·학습** (또는 `run_train.bat` 더블클릭)
   ```bat
   set REAL_UPWEIGHT=4
   set CONTRASTIVE_UPWEIGHT=2
   python merge_and_split.py
   set EPOCHS=8
   python train_context_split.py out_mytrain --from warm
   ```

6. **결과 확인**: `[TEST · 실데이터]` 리포트에서 **놀람·당황·슬픔·고마움 f1이 0에서 올라오는지** 보세요. 그게 이번 수집의 성공 지표예요.

## 체크리스트
- [ ] 놀람 대화 2~3개 (~40개 메시지)
- [ ] 당황 대화 2~3개
- [ ] 슬픔 대화 2~3개 (가상 설정)
- [ ] 고마움 대화 2~3개
- [ ] 각 파일 label 채움 → `modify_data/`에 `to_label_*` 이름으로
- [ ] `run_train.bat` 실행 → 4개 감정 f1 상승 확인
