# Emour 시연 시나리오

## 1. 시연 계정

| 구분 | 이메일 | 비밀번호 | 역할 |
|---|---|---|---|
| 사용자 A | `test1@ssafy.com` | `password123!` | 본인 |
| 사용자 B | `test2@ssafy.com` | `password123!` | 연인 |

## 2. 핵심 시연 흐름

### 2-1. 회원가입 및 로그인

2. ② 로그인

### 2-2. 이메일 인증 및 회원정보 입력

![이메일 인증 및 회원정보 입력](<./시나리오 사진/프레젠테이션2.png>)

1. ① 이메일 인증 코드 입력
2. ② 회원정보 입력 후 회원가입 완료

### 2-3. 커플 방 연결 및 진입

![커플 방 연결](<./시나리오 사진/프레젠테이션3.png>)

1. ① 사용자 A가 방을 생성한다.
2. ② 사용자 B가 전달받은 코드를 입력해 방에 참여한다.
3. 로그인 후 연결된 `roomId`를 기준으로 메인 화면에 진입하는지 확인한다.
4. 연인 프로필과 커플 연결 상태를 확인한다.

### 2-4. 실시간 채팅

![실시간 채팅](<./시나리오 사진/프레젠테이션4.png>)

```text
<2안: 일상 대화>
A: 자기야, 아직 많이 아파? (걱정)
B: 약도 먹었는데 아직도 아파ㅠㅠ (괴로움)
B: 혼잔데 아프기까지 하니까 되게 서럽다... (상처)
A: 많이 힘들겠다. (슬픔)
A: 내가 죽 사들고 너네 집까지 갈게. (슬픔)
A: 금방 갈 테니까 걱정하지 마. (걱정)
B: 뭐? 지금 오겠다고?? (놀람)
B: 나 진짜진짜 괜찮아, 너 집 되게 멀잖아ㅠㅠ (슬픔)
A: 신경 안 써도 괜찮아. (편안함)
A: 내가 너 보고 싶어서 가는 거야. (설렘)
B: 진짜 고마워... (감사)
B: 조심해서 와. (걱정)
A: 응, 금방 갈게. (평범)
```

1. ① 미리 만들어 놓은 대화 시나리오를 입력하고 전송
2. ② AI 메시지 교정 확인
3. ③ 사진을 보내 실시간으로 표시되고 삭제되는지 확인
4. ④ 메시지 검색 확인
5. ⑤ 메시지에 리액션을 남기고 북마크
